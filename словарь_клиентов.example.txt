# Личный словарь обезличивателя — образец
#
# Скопируйте этот файл как «словарь_клиентов.txt» в папку со скриптом
# и впишите названия своих клиентов и проектов. Настоящий файл
# в .gitignore и в репозиторий не попадает.
#
# Формат: одна запись на строку. По умолчанию метка КОМПАНИЯ.
# Другую метку можно указать через | (КОМПАНИЯ, ФИО, ПРОЕКТ или своя).
# Для русских названий падежные окончания подбираются автоматически.
#
# Примеры (удалите и впишите свои):

FinClever
Ромашка Трейд
Солнечная Долина | ПРОЕКТ
Малахова Ксения | ФИО
